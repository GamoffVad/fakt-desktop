# Провайдеры LLM

FAKT обращается к модели дважды:

1. **Определение структуры** — один запрос на файл. Модели отправляются только первые 5 строк; расширенный образец — только по отдельной команде пользователя.
2. **Извлечение лиц и фактов** — пакеты записей (по умолчанию до 10 записей в запросе). Каждая запись проходит модель.

Ответы проверяются приложением: JSON Schema, наличие результата для каждой записи, соответствие значений тексту записи, даты, форматы идентификаторов. Модель не выполняет код; тексты файлов передаются как данные, а не инструкции.

## Работа без интернета

Приложению интернет не нужен. Для полностью автономной работы используйте модель в своей сети:

| Вариант | Профиль FAKT | Адрес по умолчанию |
|---|---|---|
| LM Studio (сервер на этой или другой машине) | «LM Studio» | `http://localhost:1234/v1` |
| Ollama | «Ollama» | `http://localhost:11434` |
| vLLM, llama.cpp server, TGI, внутренний шлюз | «OpenAI Compatible» | `http://localhost:8000/v1` |

Модель должна целиком помещаться в видеопамять — иначе ответы будут очень медленными (на машине разработки модель 27B в Q4 на GPU 16 ГБ не ответила за 10 минут). Для 16 ГБ разумны модели 7–14B. Приложение показывает, куда уходят данные: локальный или внутренний адрес — «данные не покидают вашу сеть», внешний — предупреждение.

## Профиль

| Поле | Назначение |
|---|---|
| Провайдер и Base URL | Адрес API. Ключ привязан к адресу (схема, хост, порт) и не отправляется на другой адрес. |
| API-ключ | Хранится в DPAPI, не отображается и не пишется в настройки и журнал. |
| Модель | Список моделей, доступных ключу («Загрузить модели», с фильтром), или точный model ID вручную. |
| Тайм-аут, объём ответа | Для медленных локальных моделей увеличьте тайм-аут. |
| Одновременных запросов, RPM, TPM | Ограничения провайдера; при 429 учитывается Retry-After. |
| Записей в пакете, предел входных токенов | Размер одного запроса извлечения; при обрезанном ответе пакет автоматически делится. |
| Температура | Отправляется, только если поддержка подтверждена тестом. |
| Структурированный ответ | «Авто» (по результату теста): JSON Schema → JSON mode → вызов инструмента → схема в промпте. |
| Заголовки | Дополнительные HTTP-заголовки; секретные хранятся в DPAPI. |
| Тарифы | Цена за 1 млн токенов с датой проверки — только для оценки стоимости; встроенных цен нет. |

**Тест извлечения** — запрос на синтетических данных. Он проверяет схему ответа, разделение ФИО, даты, телефоны без добавления кода страны, несколько лиц в записи, игнорирование «инструкций» в данных, и определяет режим структурированного ответа. Без успешного теста обработка не запускается.

## Провайдеры

| Провайдер | Base URL по умолчанию | Ключ | Особенности |
|---|---|---|---|
| OpenAI | `https://api.openai.com/v1` | обязателен | Chat Completions или Responses API (`store=false`), строгая JSON Schema. |
| OpenAI Compatible | `http://localhost:8000/v1` | по желанию | Любой совместимый сервер; способ авторизации, пути и параметры настраиваются. Возможности проверяются тестом. |
| Azure OpenAI | `https://<resource>.openai.azure.com` | обязателен | v1 или классический режим с deployment и api-version. |
| Anthropic | `https://api.anthropic.com` | обязателен | `x-api-key`, `anthropic-version: 2023-06-01`; structured outputs (`output_config.format`) или принудительный вызов инструмента. Ограничение числа строк в схеме не передаётся (API его не принимает) — задаётся текстом запроса. |
| Google Gemini | `https://generativelanguage.googleapis.com` | обязателен | `x-goog-api-key`; `responseJsonSchema` или `responseSchema`. Неверный ключ приходит кодом 400. |
| Mistral | `https://api.mistral.ai/v1` | обязателен | json_schema / json_object. |
| DeepSeek | `https://api.deepseek.com` | обязателен | Только `json_object`: схема передаётся в запросе и проверяется приложением. С Windows 7 напрямую недоступен (шифронаборы TLS). |
| Qwen / Alibaba Cloud Model Studio | `https://dashscope-intl.aliyuncs.com/compatible-mode/v1` | обязателен | Регион выбирается адресом; параметр «размышлений» отключается для извлечения. |
| xAI | `https://api.x.ai/v1` | обязателен | Совместимый API. |
| Groq | `https://api.groq.com/openai/v1` | обязателен | Строгая схема — только у части моделей; иначе json_object. |
| OpenRouter | `https://openrouter.ai/api/v1` | обязателен | Список моделей, доступных ключу; строгость схемы зависит от конечного провайдера; ошибка может прийти с HTTP 200. |
| Together AI | `https://api.together.xyz/v1` | обязателен | Совместимый API. |
| Fireworks AI | `https://api.fireworks.ai/inference/v1` | обязателен | Совместимый API; постраничный список моделей. |
| Ollama | `http://localhost:11434` | по желанию | Нативный API (`format` = JSON Schema). |
| LM Studio | `http://localhost:1234/v1` | по желанию | Совместимый API и нативный список моделей; первый запрос к незагруженной модели выполняется долго. |

## Что проверено реально

| Провайдер | Проверка |
|---|---|
| OpenRouter → `openai/gpt-4.1-mini` | Соединение, список моделей (457), тест извлечения (JSON Schema), определение структуры 10 файлов разных форматов, обработка 5 файлов (107 записей) в SQL Server, поиск и карточка — **пройдено** в нескольких прогонах; полнота и точность по лицам 99,2 %. |
| OpenRouter → `qwen/qwen3-235b-a22b-2507` | См. `docs/TEST_REPORT.md`. |
| OpenRouter → `google/gemini-2.5-flash-lite` | Не выполнено: провайдер отказал в доступе для учётной записи («Blocked by Google AI Studio», региональное ограничение). Приложение корректно сообщило причину. |
| LM Studio (локально, модель 27B) | Сервер и список моделей доступны; модель не ответила за 10 минут (не помещается в 16 ГБ видеопамяти) — проверка извлечения не выполнена. |
| Остальные адаптеры | Проверены модульными тестами с имитацией HTTP-сервера (форма запросов, заголовки, коды ошибок, 429 с Retry-After, обрезанные и некорректные ответы). Реальные ключи этих провайдеров не использовались — имитатор не доказывает работу провайдера. |
