# Совместимость FAKT

Документ фиксирует точные версии компонентов и статус их проверки. Первая редакция составлена в начале разработки (24.09.2026) по официальным источникам: `docs/research/platform-research.md`, `docs/research/providers-research.md`. Статусы обновлены по итогам проверок 25.09.2026 (`docs/TEST_REPORT.md`).

Статусы:

- **проверено** — подтверждено запуском или тестом; в примечании указано, где именно.
- **требует проверки** — выбрано по документации, запуском на целевой платформе не подтверждено.
- **не поддерживается** — известно, что не работает или официально не поддерживается.

> Машина разработки — Windows 11 Pro 10.0.26200 x64. **Windows 7 SP1 недоступна**, поэтому работа на целевой ОС не проверена. Всё, что помечено «проверено», проверено на Windows 11, если не сказано иное.

## 4. TLS и сеть

| Аспект | Статус | Примечание |
|---|---|---|
| TLS 1.2 для HttpClient на Windows 7 | требует проверки | Для клиента по умолчанию выключен. Приложение явно задаёт `SecurityProtocolType.Tls12` на Windows 7. Рекомендуется также включить TLS 1.2 в реестре SChannel: см. `docs/SETUP.md`. |
| TLS 1.2 для SQL-подключения на Windows 7 | требует проверки | SqlClient использует SChannel ОС, поэтому нужны ключи реестра `SCHANNEL\Protocols\TLS 1.2\Client`: `Enabled=1`, `DisabledByDefault=0`. |
| TLS 1.3 на Windows 7 | не поддерживается | Отсутствует в SChannel Windows 7. Сервер, принимающий только TLS 1.3, недоступен. |
| Шифронаборы ECDHE-RSA-AES-GCM | не поддерживается | В Windows 7 их нет. Серверы, принимающие только эти наборы, недоступны. |
| DeepSeek API напрямую с Windows 7 | не поддерживается (эмпирически) | Эмуляция рукопожатия с шифрами Windows 7 не прошла (24.09.2026). Используйте шлюз или прокси на современной ОС либо OpenRouter. Требует проверки на реальной Windows 7. |
| OpenAI, Anthropic, Gemini, OpenRouter, Mistral, Groq с Windows 7 | требует проверки | Эмуляция рукопожатия прошла. Проверка на реальной Windows 7 не выполнялась. |
| Проверка сертификатов | проверено (код) | Не отключается. `TrustServerCertificate` для SQL выключен по умолчанию; включение показывается как предупреждение безопасности. |
| Корневые сертификаты Windows 7 | требует проверки | Без обновления корневых сертификатов ОС подключение к современным HTTPS-сервисам может не работать. |

## 8. Дополнительный режим

Если нужная интеграция не заработает на Windows 7, например TLS к конкретному провайдеру или бинарные пакеты worker, допустим отдельный режим: worker или шлюз API работает на современной машине, а WPF-клиент остаётся на Windows 7. Это отдельная конфигурация, а не скрытая замена локальной обработки. Для LLM такой режим уже работает через профиль «OpenAI Compatible» с Base URL внутреннего шлюза.
